# Angular 22.3 next

Branch: `angular-22.3-next`, from `master` at `0d41ed7`.

## Goal

Move the app to Angular's `next` release (22.3.0-next) and use its new template features.
The work stops and is reported if the update breaks more than a small fix repairs.

## Steps

One commit per step. `npm run build` passes after each step.

1. Update the `@angular/*` packages to the `next` dist-tag with `ng update`, and apply its
   migrations. TypeScript stays at 6.0.3, which the next releases still accept (`>=6.0 <6.1`).
   Done when: the build passes and the e2e suite passes, or only a small, explained
   rendering change differs.
2. Set `strictUnclaimedEventNames: true` in `angularCompilerOptions`. On 22.2.5 the flag did
   nothing: renaming `(click)` to `(clicked)` on the Start button still built.
   Done when: the same rename fails the build with a diagnostic, the rename is reverted, and
   every real misspelled binding the flag reports is fixed.
3. Make members that only their own template or host bindings read `private`. Inputs,
   outputs, models, queries, and members that the framework or other code reaches stay public.
   Done when: the build passes and the count per file is reported.
4. Add `disabledInteractive` to the three "Change to ..." items in the task menu, with a
   `matTooltip` on the disabled one. Keyboard focus can then reach the current-state item.
   Done when: a screenshot shows the menu with the tooltip.
5. Make `gameStateGuard` return a `RedirectCommand` instead of calling `router.navigate()`.
   Done when: the redirect target and behaviour are unchanged.
6. Replace the three `[ngClass]` uses with `[class.x]` bindings and drop the `NgClass`
   imports. Done when: the same classes apply under the same conditions.
7. Update `CLAUDE.md` where a fact changed.
   Done when: it names the `next` tracking and the `private` rule.

## Final checks

The full e2e suite runs once at the end. Snapshots change only for the step 4 menu or a
pure rendering change from the update.
